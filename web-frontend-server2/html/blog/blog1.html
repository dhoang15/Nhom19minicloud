Bài 1: Tổng quan kiến trúc MyMiniCloud 9 Server & Mạng nội bộ cloud-net

1. Mô hình Cloud thu nhỏ (MyMiniCloud)

Hệ thống MyMiniCloud của Nhóm 19 mô phỏng đầy đủ các dịch vụ cốt lõi của một nền tảng đám mây thực tế (như AWS, GCP, Azure) thông qua 9 loại máy chủ đóng gói bằng Docker container:

  • Web Frontend Server (Nginx): Cung cấp giao diện tĩnh tại / và hệ thống bài viết tại /blog/ (tương đương Amazon S3 Static Hosting / CloudFront).
  • Application Backend Server (Flask): Cung cấp REST API /hello, /student và xác thực OIDC /secure.
  • Relational Database Server (MariaDB): Quản lý cơ sở dữ liệu quan hệ minicloud và studentdb.
  • Authentication & Identity Server (Keycloak): Đóng vai trò Identity Provider (IdP) cấp phát JWT token theo chuẩn OpenID Connect.
  • Object Storage Server (MinIO): Hệ thống lưu trữ đối tượng tương thích S3 cho ảnh đại diện (profile-pics) và tài liệu (documents).
  • Internal DNS Server (Bind9): Quản lý phân giải tên miền nội bộ trong vùng cloud.local.
  • Monitoring & Visualization (Prometheus, Node Exporter, Grafana): Thu thập chỉ số phần cứng/container và trực quan hóa trên bảng điều khiển.
  • API Gateway / Reverse Proxy (Nginx): Điểm truy cập hợp nhất tại cổng 80 và cân bằng tải giữa các Web Server.

2. Giao tiếp nội bộ qua mạng Docker cloud-net

Toàn bộ các container kết nối vào chung một mạng bridge định nghĩa sẵn tên là cloud-net. Nhờ cơ chế Embedded DNS của Docker kết hợp cùng Bind9, các máy chủ có thể gọi nhau trực tiếp qua tên định danh dịch vụ (ví dụ http://web-frontend-server:80 hoặc http://object-storage-server:9000) mà không phụ thuộc vào địa chỉ IP động.
