Bài 3: Lưu trữ phi cấu trúc với MinIO Object Storage (S3-Compatible)

1. Kiến trúc MinIO trong MyMiniCloud

MinIO đóng vai trò là Object Storage Server tương thích hoàn toàn với giao thức Amazon S3 API. Dịch vụ chạy trên hai cổng tách biệt:

  • Cổng 9000 (S3 API Endpoint): Phục vụ các yêu cầu đọc/ghi đối tượng từ ứng dụng, MinIO Client (mc) hoặc truy cập trực tiếp qua URL public object.
  • Cổng 9001 (Web Console): Cung cấp giao diện quản trị trực quan để quản lý Buckets, Objects, Access Policies và giám sát dung lượng.
  • Lưu trữ bền vững (Persistent Volume): Thư mục ./object-storage-server/data trên máy chủ host được ánh xạ vào /data bên trong container, đảm bảo dữ liệu không bị mất khi khởi động lại container.

2. Thiết kế hai Bucket: profile-pics và documents

Theo yêu cầu mở rộng của đề tài, hệ thống tổ chức dữ liệu phi cấu trúc thành các bucket chuyên biệt:

  • Bucket profile-pics: Lưu trữ ảnh đại diện cá nhân (avatar.jpg). Bucket này được thiết lập chính sách truy cập public (anonymous download) để trình duyệt có thể hiển thị trực tiếp ảnh qua đường dẫn http://localhost:9000/profile-pics/avatar.jpg.
  • Bucket documents: Lưu trữ tệp PDF báo cáo cuối kỳ (bao-cao-cuoi-ky-nhom19.pdf). Bucket có thể giữ ở chế độ riêng tư (private, truy cập qua Presigned URL) hoặc cấp quyền tải xuống để kiểm thử.
